- CI now runs every `backend/tests/test_*.py` by unittest discovery instead of a hand-written list of modules. Eight test files, the capacity and scan-slot tests among them, had run in no workflow, so a change that broke them still passed. Six of them were plain test functions that unittest never collects; `function_tests()` in `backend/tests/__init__.py` runs them now, 79 more tests in all. `scripts/check_tests_run.py --check` fails when a Python test file runs in no workflow or gives unittest no test, so the list cannot drift again (#228).
- `test_regression_functional` no longer leaves its fake PaddleOCR installed for the files that run after it. Discovery ran it before `test_server_pipeline`, whose refine test then counted a line recovered by the fake reader.
