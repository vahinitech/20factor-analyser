- Internal access API at `/internal/access/v1` (`backend/access_api.py`): a service on the private network can grant Pro (customer, key and grant in one transaction), change a subscription, issue and revoke keys and look up a customer or a key, without opening the subscription ledger itself. It is off unless `VAHINI_ACCESS_API_TOKEN_FILE` names a token of at least 32 characters, answers 404 to anything that came through a proxy and 401 to a wrong token. New schemas `access-request`, `access-customer`, `access-key` and `access-key-lookup`; `entitlements.grant` and `check_state` keep the API and the command line on one set of rules.
