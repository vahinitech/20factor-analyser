- docs/20-languages.md: the design for scoring more scripts and languages (German, Hindi, the English variants, Telugu beyond ink geometry). Language facts move out of the scoring code into packs that inherit script, language and locale; each line gets a script decision from the worksheet, the family's choice, an image classifier and the reader, refusing when they disagree; each factor declares what it needs and is "Not measured" without it; maturity levels gate what may be scored and claimed; a language model may help decide the script and read, behind the same guards as any reader, off by default and local unless the owner approves an API, and never produces a factor score. Section 17 sets the order tools run in: per-task ladders built offline from measured quality and cost (cheapest first, a stage kept only if it is better than every cheaper one), escalation per line on doubt, and a refusal with retry, never a quiet substitute, when a needed stage is down, so the same photo always takes the same path. It lists every hardcoded Latin assumption with its line, the build order starting with a change that moves no benchmark number, and the request `lang` contract change.
