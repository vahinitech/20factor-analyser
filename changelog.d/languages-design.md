- docs/20-languages.md: the design for scoring more scripts and languages (German, Hindi, the English variants, Telugu beyond ink geometry). Language facts move out of the scoring code into packs that inherit script, language and locale; each line gets a script decision from the worksheet, the family's choice, an image classifier and the reader, refusing when they disagree; each factor declares what it needs and is "Not measured" without it; maturity levels gate what may be scored and claimed; a language model may help decide the script and read, behind the same guards as any reader, off by default and local unless the owner approves an API, and never produces a factor score. Section 17 sets the order tools run in: per-task ladders built offline from measured quality and cost (cheapest first, a stage kept only if it is better than every cheaper one), escalation per line on doubt, and a refusal with retry, never a quiet substitute, when a needed stage is down, so the same photo always takes the same path. Mermaid diagrams show the whole path with every exit, each ladder's fallbacks, the script decision, and CPU, GPU and memory handling (stages declare their memory and device, everything a ladder can reach loads at start-up and counts in the capacity plan, GPU work runs as a separate service with its own slots and queue); the two overview diagrams are also in docs/01-system-architecture.md, labelled as planned. Section 18 adds school, class and child profiles for custom rules and exceptions (declarative, hashed, unable to change a formula or raise a score by removing evidence) and language skills as a separate layer 7 for spelling, grammar and phonetic findings on trusted text. Section 19 records a self-review: twelve gaps, among them English checks in craft.js that would run on German pages, no age in the request, and a reading model that could be steered by text on the page, each with its fix and issue. It lists every hardcoded Latin assumption with its line, the build order starting with a change that moves no benchmark number, and the request `lang` contract change.
