- `deployment/grant-pro.sh stage|prod "<label>" <last day>` gives Pro in one command, following docs/17: it backs up the ledger, creates the customer, issues a random key, grants Pro until the end of that day in India time, checks the key and asks the site what it gets. The key is never printed; it goes to a 0600 file under `~/secrets/pro-keys/`, and a line without the key goes to the private register. It finds the admin tool in images from before and after the backend folder sort. docs/17 has a quick start and a section on keys shared by a group, and the guide is linked from both READMEs, AGENTS.md and CLAUDE.md.
