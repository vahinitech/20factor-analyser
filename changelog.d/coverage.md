- CI measures test coverage: the backend tests run under coverage.py with branch coverage (`.coveragerc`) and every `tests/*.test.mjs` runs under c8 (`.c8rc.json`, `npm run coverage:frontend`). Each run writes a per-file table to the job summary and uploads an HTML report as an artifact (`coverage-backend`, `coverage-frontend`). No third-party coverage service (#232).
- `coverage-baseline.json` is a ratchet, checked by `scripts/coverage_ratchet.py --check`: the total and each file may not drop more than 0.5 points, and files in `backend/languages/` and `backend/scoring_parts/` stay at 90% or more, apart from dated exceptions recorded at today's number that can only go up. A PR that raises coverage raises the baseline with `--update`.
- The node tests load frontend sources through `tests/run-source.mjs`, which gives each file its real path. Without it V8 called the code "evalmachine" and c8 could not count it.
