- The report request's `lang` accepts BCP 47 tags and comma lists: `en,te`, `te-Telu-IN`, `en-Latn-GB,te`. The server already read comma lists, but `report-request.schema.json` refused them. The server reads each tag by its language subtag (`backend/lang_tags.py`), so `te-Telu-IN` reads, scores and caches exactly as `te`, and the two share one cache entry. Every value the old pattern allowed, `auto` and 2 to 8 lowercase letters, stays valid and behaves as before. Part of #212; the Umbrella contracts copy needs the same sync after merge.
