- `subscription_admin.py show-customer CUSTOMER_ID` prints a customer's plan, the access their keys get now (worked out by the same code as `access_for`), each key id with its revoked flag and creation time, and the audit history, without key digests. `check-key --secret-file PATH` reads a key from a private 0600 file and prints which customer and key id it belongs to and its access, never the key. Both open the ledger read-only. They replace the hand-written SQL in docs/17-access-and-trials.md.
- Issuing and revoking a key now write `key:issue:<key id>` and `key:revoke:<key id>` to the audit table, so a customer's history shows every key change. The rows hold the key id only, never the secret or its digest.
