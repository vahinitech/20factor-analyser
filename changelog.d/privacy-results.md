- CI records the five privacy tests that vahinitech.com's status page lists under "Privacy tests we run" (the privacy card, the print popup, "Who is checking?" on the page and on the server, and names blanked from the page). On each push to main, `scripts/privacy_results.py` writes pass or fail per test and the time, nothing else, as the `privacy-tests-backend` and `privacy-tests-browser` artifacts, kept 90 days. The website's release fetches them for the analyser commit it ships. A test skipped after an earlier step failed gets no result. The two server tests also run alone, early in the Python job, so a lint failure cannot hide them.
