- CI records the privacy tests that vahinitech.com's status page lists under "Privacy tests we run": the privacy card, the print popup and "Who is checking?" on the page (browser steps), and names blanked, "Who is checking?" on the server and the accurate-report checks for DPDP section 8(3) (reader down, sideways photos, printed text, maths pages, unread Telugu pages, the benchmark rules). On each push to main, `scripts/privacy_results.py` writes pass or fail per test file and the time, nothing else, as the `privacy-tests-backend` and `privacy-tests-browser` artifacts, kept 90 days; the website's release fetches them for the analyser commit it ships. The Python results are read from the discovery run's output (now also written to `unittest.log`), so nothing runs twice; a file that did not run, or a run that did not finish, gets no result.
