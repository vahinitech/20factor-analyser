- When the handwriting reader cannot read a page (its engine will not load, or a run fails under memory pressure), the server answers 503 with `error_code: "ocr_unavailable"` and `Retry-After: 60`, and the page asks the visitor to try again in a minute. Such pages used to be scored from rough line shapes instead, so the same photo could score differently while the reader was down (#112). The refusal is not cached and does not use up a free check. A page the reader read without error and found no lines on is still measured from line shapes, as before.
