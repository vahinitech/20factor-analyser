- Test payloads that look like malware are now joined with `b"".join(...)` instead of `+`. Python folds two literals joined with `+` into one constant when it compiles a file, so the cached `.pyc` of `test_image_formats.py` held the whole PHP payload and the server's nightly maldet scan flagged a copy in `/tmp` on 2026-10-19, although the source held only the parts. `test_scanner_strings.py` now also compiles every tracked `.py` file and checks its constants, nested functions included, against the same patterns and maldet signatures, so a folded literal fails the test.
