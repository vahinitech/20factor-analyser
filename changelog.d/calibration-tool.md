- Added `scripts/calibrate.py`, which proposes score scales from a set of neat reference handwriting (a benchmark set marked `"role": "neat-reference"`): the tightest scale that puts the set's median at 9.0 and its 10th percentile in the Strong band, checked against every planted mistake in `benchmarks/factors/expected.json`. It changes no scale; a factor that cannot meet both is reported with its numbers. The factor tests workflow runs it on the UJI pages as a tool test only, since they are not neat writing.
