- Smaller image attack surface (owner decision, 2026-10-09). The server decodes only JPEG, PNG and WebP (plus PDF); the other formats Pillow can open, about forty, are refused as 422 before their decoder runs. The image runs as user 10001 instead of root, with `HOME=/tmp` and no `.pyc` writes, and owns its model and database folders so new volumes start with the right owner; vahini-web runs it read-only with no capabilities. Pillow is pinned to 12.3.0. `SECURITY.md` has the upload and image rules, and CLAUDE.md, AGENTS.md, the Copilot instructions and the report skill point to them. `backend/tests/test_image_formats.py` covers formats and hardening.
