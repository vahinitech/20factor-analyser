- Every successful compact report now keeps a small record so a family can compare a later check with an earlier one: scores, comparability counts, where each factor was measured and the day of the check. Never the photo, a cut-out, the words read, a caption, the file name, the typed passage, the access key, the address, the browser or the time. A random receipt goes back to the browser's saved checks and is the only way to read the record (`GET /api/v2/reports/{id}` with `X-Report-Token`). Records expire 12 months after the family's last check, a new check renews them, and "Forget" deletes them. On when `VAHINI_REPORT_STORE_DIR` is set. `backend/report_store.py`, docs/15-persistence.md.
